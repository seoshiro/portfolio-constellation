03 / Кейс

Как это устроено

  1. 01

    SVG связывает звёзды, список и точные параметры нот. Угол — время, радиус — высота; клавиатура и числовые настройки дополняют перетаскивание.SVG связывает звёзды, список и точные параметры нот. Угол — время, радиус — высота; клавиатура и числовые настройки дополняют перетаскивание.

  2. 02

    Web Audio синтезирует три голоса. Звук запускается только по действию пользователя, аудиочасы управляют курсором, скрытая вкладка приостанавливает воспроизведение.Web Audio синтезирует три голоса. Звук запускается только по действию пользователя, аудиочасы управляют курсором, скрытая вкладка приостанавливает воспроизведение.

  3. 03

    Обучение проходит в отдельном пространстве. Локальные записи и входящие партитуры проверяются; ошибки сохранения видны, перенос через JSON не требует сервера.Обучение проходит в отдельном пространстве.
