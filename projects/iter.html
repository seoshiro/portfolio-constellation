03 / Кейс

Как это устроено

  1. 01

    Планировщик фильтрует рёбра графа по условиям и ищет кратчайший доступный путь. Закрытый участок и неизвестное состояние показаны явно.Планировщик фильтрует рёбра графа по условиям и ищет кратчайший доступный путь. Закрытый участок и неизвестное состояние показаны явно.

  2. 02

    Текст, SVG и Three.js используют общие идентификаторы узлов и рёбер. При отсутствии WebGL маршрут остаётся в схеме и текстовых шагах.Текст, SVG и Three.js используют общие идентификаторы узлов и рёбер. При отсутствии WebGL маршрут остаётся в схеме и текстовых шагах.

  3. 03

    Web Speech API озвучивает маршрут по явному запросу. Учебная стена препятствий поддерживает сообщения через существующий публичный сервис, с серверной проверкой данных.Web Speech API озвучивает маршрут по явному запросу. Учебная стена препятствий поддерживает сообщения через существующий публичный сервис, с серверной проверкой данных.
