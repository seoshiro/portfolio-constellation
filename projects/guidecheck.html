10 / СИСТЕМЫ ПРОВЕРКИ

GuideCheck

Изменения инструкции
и история проверок

Сравните версии инструкции: текст, ссылки, изображения и порядок шагов. Записывайте результаты ручной проверки для каждого шага.Сравните версии инструкции: текст, ссылки, изображения и порядок шагов. Записывайте результаты ручной проверки для каждого шага.

Открыть приложение ↗Исходный код ↗
  • TypeScript
  • IndexedDB
  • SQLite
  • Playwright

01

С чего начать

Откройте инструкцию и её новую версию. Сравните изменения, затем отметьте проверенные шаги и запишите результат.Откройте инструкцию и её новую версию. Сравните изменения, затем отметьте проверенные шаги и запишите результат.

02

Результат

Список изменений, история ручных проверок и исправлений, резервная копия рабочей области.Список изменений, история ручных проверок и исправлений, резервная копия рабочей области.

03 / Кейс

Как это устроено

  1. 01

    Постоянные ID связывают шаги между версиями. Изменения текста, ссылок, скриншотов и порядка видны явно.Постоянные ID связывают шаги между версиями. Изменения текста, ссылок, скриншотов и порядка видны явно.

  2. 02

    Результат проверки переносится, только если шаг и контекст инструкции полностью совпадают.Результат проверки переносится, только если шаг и контекст инструкции полностью совпадают.

  3. 03

    Браузерная версия использует атомарные транзакции IndexedDB. Необязательная локальная версия хранит данные в SQLite.Браузерная версия использует атомарные транзакции IndexedDB. Необязательная локальная версия хранит данные в SQLite.
