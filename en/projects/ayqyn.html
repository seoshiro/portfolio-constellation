04 / Local applications

AYQYN

Observe with context.
Leave decisions to people.

A Windows local proctoring prototype: participant consent, camera preparation, on-device observations and a separate human review of events.

Open application ↗Source code ↗
  • Electron
  • JavaScript
  • ONNX Runtime
  • MediaPipe

Independent project. Design, implementation and verification are documented in the source.

01

The starting point

Explicit participant consent, calibration and a local session. A test scenario and browser replay introduce the workflow.

02

The result

A contextual observation timeline, confirmed or rejected decisions with reasons, and a JSON report without images.

03 / Case study

Under the surface

  1. 01

    YOLO and MediaPipe run on the device in a separate CV worker. Processing consent and snapshot consent are separate; snapshots default to off.

  2. 02

    Events show duration and context. Reviewers must explain their decisions; observations never automatically become accusations.

  3. 03

    Electron isolates the interface and bounds IPC. Reports exclude images, retention is visible and the browser replay uses licensed test photographs.

04 / Case study

Practical boundaries

A prototype for Qostanai AI Industry Hackathon 2026, with no winning award claimed. Gaze direction is approximate and observations do not prove misconduct. It is not a certified examination environment. Replay is not a camera accuracy test.
