# Локальная реализация Signal / Personal Atlas

Результат: статическая версия портфолио Signal / Personal Atlas. Реализация и проверки выполнены в отдельном checkout. После первоначального локального этапа пользователь явно разрешил commit/push и публикацию через существующий GitHub Pages. Этот отчёт описывает pre-release QA; точный pin выпуска фиксируется в publisher README и live version.json.

## Как открыть

Команды выполняются из корня checkout `portfolio-constellation`.

В этой папке запустить `npm run preview`, затем открыть `http://127.0.0.1:5318/`. На момент передачи локальный сервер уже работает. Маршруты `/`, `/en/`, `/kk/`; ссылки на проекты и все кейсы сохранены. Для просмотра готового `dist` достаточно Node.js, установка зависимостей не требуется. Для изменения исходников используются существующие lockfile и зависимости.

База: `bdffb0e339ac92eb24a8ea80152a76fc44528d46`, `seoshiro/portfolio-constellation`. Базовый checkout сохранён. Точный source SHA выпуска определяется после commit; `dist/version.json` содержит sourceCommit и отдельный признак локальных изменений.

## Что реализовано

- Зонд появляется у входа, проходит три станции и сопровождает чтение каталога; приёмник раскрывается при приближении к финалу.
- Desktop: одна сцена высотой 260svh со sticky viewport и обратимым прогрессом 0–1. Mobile: компактная диорама и три последовательные HTML-панели без закрепления.
- Три плана звёзд, передние осколки, световой трос, инерция зонда и конечная реакция фрагмента на сбор. Текст не движется вместе с глубиной.
- Единый WorldState: секция, прогресс, направление, фактическая сглаженная скорость, указатель, приближение, раскрытие, квест, кульминация и настройки.
- Один opt-in AudioContext; music, ambience и SFX направлены в master. Сохранён исходный оригинальный score; добавлены процедурный солнечный ветер, отклики остановки/сбора/активации, cooldown, ограничение голосов и ducking.
- Три сохраняемых фрагмента, защита от повторного начисления, сброс, отмена подготовки при сбросе и сохранение завершённого состояния. Квест не закрывает кейсы и контакты.
- Сохранены реальные тексты и скриншоты 11 проектов, RU/EN/KK, Onest/Manrope, угловой курсор, loader и case/back/Escape. AYQYN и другие приложения не изменялись.

## Проверки и результаты

Среда: Windows, Node.js 24.18.0, TypeScript 5.9.3, Vite 7.3.6, Playwright 1.63.0, установленный Chrome 155.0.8059.39. Новых зависимостей нет.

| Проверка | Результат |
|---|---|
| `npm run build` | PASS: 40 статических HTML-маршрутов |
| `npm run lint`, `npm run typecheck`, `git diff --check` | PASS |
| `npm test` | PASS: 16 unit/content/audio/state tests, включая 4 новых содержательных теста |
| `npm run check:artifact` | PASS: 81,263 байта JavaScript при бюджете 125,000; отсутствующих внутренних файлов нет |
| Полная browser regression | 109 сценариев: 106 PASS, 3 FAIL на обнаруженном мобильном перекрытии. Дефект исправлен; весь затронутый набор из 21 сценария затем PASS. |
| Повторный финальный набор | 29/30 PASS; единственный отказ нового End/Home-теста не повторился изолированно. Тест ожидал видимость footer, а не окончание нативной прокрутки End. После усиления ожидания до фактического конца документа выполнены 3/3 успешных повторения. Отчёты `evidence/final/recheck.json`, `keyboard-recheck.json`. |
| Матрица 320/360/390/768/1440 × RU/EN/KK | PASS: три станции, реальные кейсы, отсутствие overflow, resize/orientation, mobile alternative и reduced motion |
| Quest | PASS: duplicate click, сбор 3/3, кульминация, reset, reset во время зарядки, reload, повреждённое/недоступное storage |
| Навигация | PASS: обычные ссылки, case open/back/Escape, история, сохранение языка и фокуса, keyboard и touch emulation |
| Audio | PASS: до согласия нет context/загрузки score; один music loop/context, общий volume/mute, повторный enable без дублей, фактический RMS, рост wind gain от скролла, ducking/recovery, controlled hidden/show, ошибки загрузки/декодирования/context |
| Accessibility | PASS: существующие и новые automated axe WCAG A/AA checks, HTML-эквиваленты canvas, видимый focus и static content без JS |
| Снимки финала | PASS: 5 ширин, ни одного pageerror или horizontal overflow; `evidence/final/capture.json` |

Единого нового запуска всех 110 сценариев после исправлений не заявляю: подтверждение состоит из полной регрессии и целевых повторных прогонов, перечисленных выше. Непроверенные слухом свойства не считаются PASS.

Производительность: отдельная четырёхсекундная прокрутка туда/обратно в закреплённой сцене, без записи экрана: 569 RAF-интервалов, median 7ms, p95 7ms, long tasks не зарегистрированы. Это частота callback в данной среде; canvas ограничен примерно 30 отрисовками/с. Это не обещание FPS на телефонах и не сравнение ускорения. Данные: `evidence/final/performance.json`.

## Ограничения

- **Слуховая оценка баланса, тембра и субъективной синхронизации: NOT TESTED.** Запись и analyser подтверждают сигнал, но не заменяют прослушивание.
- **Настоящее скрытие вкладки: NOT TESTED.** При `bringToFront` headless Chrome оставил `document.hidden=false`; это честно записано в `tab-restore.json`. Controlled visibility events проверили suspend/resume и отсутствие восстановления выключенного звука.
- Физические iOS/Android, Safari, разные реальные аудиоустройства: NOT TESTED. Touch и orientation проверены в Chrome emulation.
- Доступность внешних приложений/репозиториев в интернете не перепроверялась; исходные реальные ссылки сохранены.
- Референс исследован сверху вниз и обратно в Chrome, с медленными остановками/большими wheel-переходами. Сохранены фон, острова, путь корабля, книга и финал. Клик FAQ блокировался перекрывающим слоем самого референса; звук референса не был прослушан. Наблюдения отделены от недоступных проверок.

Публикация разрешена отдельным явным согласием пользователя после локальной реализации. Требуется успешная проверка точного source SHA в CI и существующем publisher; платные сервисы и соседние приложения исключены.
