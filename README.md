# seoshiro / Personal Atlas

New independent portfolio source repository for Beibars Ileskhan. Target publication: https://seoshiro.github.io/.

## Current checkpoint

Repository setup and source/content preflight are complete. The application is not implemented or published yet: the three required original visual references could not be materialized by the current Library helper on Windows. They have not been visually inspected, and their extracted descriptions are not being used as substitutes for their pixels.

The existing public portfolio remains unchanged and available. Its precise source baseline is archived at [`archive/pre-constellation-2026-10-10`](https://github.com/seoshiro/seoshiro.github.io/tree/archive/pre-constellation-2026-10-10), commit `a06ece34d9a084d529cfa406f22b0436a746ae98`.

See [preflight](docs/PREFLIGHT.md), [publishing design](docs/PUBLISHING.md), and [verified project sources](data/project-sources.json). These are preparation records, not a release or proof of completed portfolio QA.

## Typography assets

Free, locally packaged Geologica and Golos Text from the official Google Fonts repository. Both fonts were checked against English, Russian and the Kazakh characters `Әә Ғғ Ққ Ңң Өө Ұұ Үү Һһ Іі` using their actual cmap tables. No missing characters were found. Their SIL Open Font License files are included alongside the fonts. Final visual font settings await the reference review and browser composition pass.

No backend, analytics, paid services, new credentials, or changes to standalone project repositories are included.
